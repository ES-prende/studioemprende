Tipos de software y ejemplos de cada uno

Cuáles son los tipos de software: de sistema, de aplicación y de programación, además de los 7 tipos más citados, con ejemplos y los más utilizados.

Respuesta rápida

Los tipos de software se agrupan en tres grandes familias: software de sistema (hace funcionar el equipo), software de aplicación (lo que usa la persona para trabajar o comunicarse) y software de programación (con el que se crea otro software). A partir de ahí se habla de 4, 5, 7 o 10 tipos según el detalle.

En esta guíaLos 3 tipos principalesLos 7 tipos de software más citadosSoftware de gestión: el que más importa a una empresaSegún su licencia

Los 3 tipos principales

  • De sistema: sistemas operativos (Windows, Linux, Android), controladores y utilidades.
  • De aplicación: ofimática, navegadores, diseño, contabilidad, TPV, CRM, ERP.
  • De programación: editores de código, compiladores y entornos de desarrollo.

Los 7 tipos de software más citados

  1. Sistemas operativos.
  2. Controladores (drivers).
  3. Utilidades: antivirus, copias de seguridad.
  4. Ofimática.
  5. Software de gestión empresarial: ERP, CRM, contabilidad, RRHH.
  6. Software de programación.
  7. Software a medida, hecho para una empresa concreta.

La versión de 4 tipos suele quedarse en sistema, aplicación, programación y utilidades.

Software de gestión: el que más importa a una empresa

Dentro del software de aplicación, el de gestión es el que ordena el negocio: TPV, contabilidad y facturación, control horario, recursos humanos o gestión de proyectos. Lo desarrollamos en qué es un software de gestión.

Según su licencia

Otra forma de clasificarlos es por cómo se distribuyen: libre, de código abierto, propietario, gratuito (freeware) o de pago por uso (SaaS). Lo explicamos en software libre y propietario y en qué es SaaS.

Preguntas frecuentes

¿Cuáles son los 4 tipos de software?

Software de sistema, de aplicación, de programación y utilidades.

¿Qué es un software de aplicación? Ejemplos

El que usa la persona para hacer tareas: Word, Excel, Chrome, WhatsApp, un TPV o un CRM.

¿Cuáles son los 5 software más utilizados?

En empresa, los más extendidos son el sistema operativo, el navegador, la ofimática, el correo y el programa de gestión o facturación.

¿Qué tipo de software es un antivirus?

Es software de utilidad, una categoría dentro del software de sistema. Su función no es que la persona haga una tarea de trabajo, sino proteger y mantener el equipo. En la misma familia están los programas de copias de seguridad, los compresores de archivos o los limpiadores de disco.

¿Un ERP es software de aplicación?

Sí. Un ERP es software de aplicación, en concreto de gestión empresarial, porque lo usan las personas para hacer su trabajo: facturar, comprar, controlar stock o ver resultados. Funciona sobre el sistema operativo y suele combinarse con otros programas de aplicación como el correo o la ofimática.

¿Qué tipo de software es ChatGPT?

Es software de aplicación que se ofrece como servicio en la nube: lo usas desde el navegador o una app sin instalar nada en tu equipo. Por dentro funciona con un modelo de inteligencia artificial, que es otro tipo de software especializado ejecutándose en servidores del proveedor.

Clasificación según dónde funciona el programa

Además de por su función, el software se clasifica por el lugar donde se ejecuta, y esta forma de verlo es la más útil al elegir programas para una empresa.

  • De escritorio: se instala en el ordenador. Ejemplo: un programa de diseño.
  • Web o en la nube: se usa desde el navegador. Ejemplo: un CRM online.
  • Móvil: apps para teléfono o tableta.
  • Embebido: va dentro de un aparato, como un datáfono o una cerradura inteligente.

Cada vez más programas combinan varias formas: una versión web para la oficina y una app para quien trabaja fuera. Sobre el modelo en la nube tienes la guía de software como servicio.

Estándar, a medida o modular: tres formas de conseguir un programa

Según cómo se fabrica y se adapta, el software de empresa puede ser estándar, a medida o modular.

El estándar se vende igual a todos los clientes y te adaptas tú a él. El desarrollado a medida nace pensando en un único cliente, con más inversión y un encaje completo. El modular parte de una base común y permite activar solo las piezas que usas y añadir desarrollos propios.

Las ventajas e inconvenientes de cada opción están en la guía de software a medida frente a estándar.

Cómo hacer un inventario del software de tu empresa

Un inventario de software es una lista de todos los programas que usa la empresa, quién los usa, cuánto cuestan y dónde guardan los datos. Se hace en una tarde y suele destapar gastos olvidados.

  1. Revisa los cargos de tarjeta y banco de los últimos doce meses.
  2. Pregunta a cada persona qué programas y apps usa para trabajar.
  3. Anota para cada uno: coste, usuarios, renovación y si guarda datos de clientes.
  4. Marca duplicados: dos programas que hacen lo mismo.
  5. Decide qué se mantiene, qué se elimina y qué se integra.

Si el gasto en suscripciones se ha disparado, mira el control del gasto en IA y suscripciones.
